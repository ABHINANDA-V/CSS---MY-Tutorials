Hello Welcome to the Element Selector World!

Element Selectors select and style HTML elements by using it's tag name.

Hello Welcome to the Class Selector World!

Class Selectors are used to select and style multiple HTML elements with the same class name.

Welcome to the ID Selector World!
ID Selector is used to select only one HTML element by using a unique id.

Hello Welcome to the Group Selector World!

Group Selectors are used to select and apply styles to multiple HTML elements.
